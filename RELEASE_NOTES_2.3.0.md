## What’s New in Tomati 2.3.0

Tomati 2.3.0 adds hands-on focus sessions and refines the Settings experience.

### New

- Focus and Break phases now enter overtime with a progressive alarm when they finish.
- Advance a session from one phase to the next with the skip control. A phase indicator shows the current phase and the next transition.
- Session progress uses the session’s selected accent color.
- Quick presets can be removed down to zero and added again from Settings.
- Session settings now use compact cards with editable names, colors, intervals, and durations.

### Improvements and fixes

- Refreshed Settings with native macOS controls and a clearer About section.
- Removed the menu bar icon selector from Settings.
- Fixed a crash that could occur after deleting the last session.
- Improved the timer popover controls and session layout.
